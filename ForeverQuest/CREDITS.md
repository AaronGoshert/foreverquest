## Changes from upstream
- Renamed the addon to ForeverQuest, with a Forever-only `ForeverQuest.toc` (Interface 16001, game type `camelot`).
- Removed guides, databases and translations for other game versions.
- Added the slash commands `/fq` and `/foreverquest`, plus `Conflict.lua`, which warns when RXPGuides is also enabled.
- Removed `Guides/forever/RestedXP-Skyborne_01.lua`, which isn't part of the public repository.
- Texture paths point at the `ForeverQuest` folder.
- Added completionist routes covering the new WoW Forever quests (in progress).
- Removed `#next` links to guides that aren't in the Forever build: '11-12 Voidwalker Quest' (Dwarf/Gnome 5-11), '6-13 Elwynn Forest' (Survival Guide 1-6 Northshire) and '22-26 ADV Wetlands 1 Mage AoE' (the ADV Mage route now ends at 22).
- Hand-placed steps for My First Alchemy Set / My First Real Potion (Westfall, alchemists only) and Excavation Tools (Loch Modan).
- Added a speed route ("ForeverQuest Speed (A)" and "ForeverQuest Speed Dungeon (A)", `Guides/forever/speed/`), generated by `tools/build_speed.py`. It keeps RestedXP's free Forever route as is and adds only the new quests that are efficient. It has no `#defaultfor`, so the completionist route stays the default.
